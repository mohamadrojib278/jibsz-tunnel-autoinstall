Perintah Instalasi GitHub & Cloudflare

          

            Seluruh file source code siap upload ke GitHub telah dibundel ke dalam file jibsz-tunnel-autoinstall.zip. Setelah diunggah ke GitHub Anda, jalankan perintah berikut di VPS Ubuntu 22.04 atau Debian 12:
          


          

            

              1. Command Install Satu Baris:
              
            

            
apt update && apt install -y curl wget unzip && wget -O setup.sh https://raw.githubusercontent.com/mohamadrojib278/jibsz-tunnel-autoinstall/main/setup.sh && chmod +x setup.sh && ./setup.sh

          


          

            
2. Setting Cloudflare Zero Trust (Mode VPS NAT):

            
    
              
  • Buka Networks → Tunnels di dashboard Cloudflare Zero Trust.
    • 
              
  • Salin token tunnel ke halaman Web Installer di port custom VPS NAT Anda.
    • 
              
  • Pada tab Public Hostname, arahkan domain ke Service Type: HTTP dan URL: localhost:80.
